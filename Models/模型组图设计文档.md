本文档先给出通用的“模型源码到 Graph_Fixed 静态图”设计方法，再以
Qwen3-0.6B 为例说明具体落地。通用部分描述可复用的流程、命名、权重登记、
算子映射和测试策略；Qwen3 部分描述 28 层 Decoder 的精确连接关系。

## 1. 背景与目标

### 1.1 背景

推理引擎在 Python 工具链端需要完成：

```text
模型源码 -> Python 端静态推理图 -> 量化 / 精度推导
        -> Shape 推导 -> 显存管理 -> 序列化
```

`Graph_Fixed` 提供 Runtime 侧静态图 IR，只回答“图里有哪些 op、tensor、
constant、输入输出，它们如何连接，按什么顺序执行”。它不依赖 torch/ATen，
不加载权重，不推导 shape/precision，也不执行 kernel。

当前仓库已经有 `Graph_Fixed` 的 C++ 实现和 Python 绑定，但还没有一个
面向具体模型的组图层。模型源码（例如 Transformers 的 `modeling_qwen3.py`）
不能直接喂给 `Graph_Fixed`：需要先把模型结构翻译成 `Graph.create_op()`、
`create_constant()`、`create_input()`、`create_output()` 和 `sort_op()` 调用。

### 1.2 目标

| 编号 | 目标 |
|------|------|
| G-01 | 给出通用的模型组图流程，适用于 Decoder-only Transformer 及类似结构。 |

## 3. 概要设计

### 3.1 分层与目录

```text
+-------------------------------------------------------------+
| Models/Qwen3/qwen3_graph_builder.py                         |
|   配置 -> 权重命名 -> op/tensor 连接 -> Graph.sort_op()      |
+------------------------------+------------------------------+
                               | mobilenet_runtime_graph
+------------------------------v------------------------------+
| Graph_Fixed/python/mobilenet_runtime_graph                  |
|   Graph / Tensor / Precision / Layout / OpType              |
+------------------------------+------------------------------+
                               | pybind11
+------------------------------v------------------------------+
| Graph_Fixed/src + include/runtime_graph                     |
|   Graph -> Op -> Tensor -> Storage；Graph_Fixed 不依赖 torch |
+-------------------------------------------------------------+
```

| 路径 | 职责 |
|------|------|
| `Models/Qwen3/config.json` | Qwen3-0.6B 超参数，兼容 Transformers 配置字段。 |
| `Models/Qwen3/qwen3_config.py` | 配置数据类、JSON 读取、字段校验、dtype 映射。 |
| `Models/Qwen3/qwen3_graph_builder.py` | 权重登记、op 创建、图连接、排序和命令行。 |
| `Models/Qwen3/test_qwen3_graph.py` | 图结构、权重形状、错误路径测试。 |
| `Models/模型组图设计文档.md` | 通用组图方法和 Qwen3 实例说明。 |

### 3.2 通用组图流程

任何 Decoder-only 模型都可以按以下六步组图：

1. **读取配置**：得到层数、hidden、FFN 宽度、head 数、KV head 数、
   head_dim、词表、norm eps、RoPE 参数、dtype 和权重绑定策略。
2. **校验配置**：拒绝不支持的 activation、bias、RoPE scaling、dtype 和
   模型变体，避免生成语义错误的图。
3. **登记常量**：按模型参数路径逐项调用 `create_constant()`，只写
   `dims/pitch/precision/layout/byte_size/data_ptr=0`。
4. **登记输入**：调用 `create_input(name, precision, layout)`，输入 op 与
   输入 tensor 同名。
5. **逐层创建 op**：按源码 forward 顺序调用 `create_op()`，把上一层输出
   tensor 作为下一层输入；residual 使用原始 activation tensor。
6. **收尾**：创建 final norm、LM Head、`create_output()`，调用
   `sort_op()`；用 `dump_ir()` 检查 inputs/constants/ops/outputs。

### 3.3 对象模型

| 对象 | 在组图层中的角色 |
|------|------------------|
| `Qwen3Config` | 只读配置，负责字段校验和派生宽度（q_width、kv_width）。 |
| `Qwen3GraphBuilder` | 一次构建一个 Qwen3 Graph，持有常量映射和中间 tensor。 |
| `Graph` | C++ IR 根对象，拥有 op/tensor/constant 和拓扑序。 |
| `Tensor` | 非拥有句柄，指向 Graph 内部的输入、激活或 constant。 |
| `Precision` | 只用于输入/触发的声明；不参与 shape 推导。 |
| `Layout` | 统一使用 `kRowMajor`。 |
| `OpType` | 决定节点语义和后续 OpEnv 选择。 |

### 3.4 Graph_Fixed 能力边界

组图层必须显式承认以下限制，不能把 `Graph_Fixed` 当成完整前端：

- `create_op()` 只接收输入 tensor 列表和输出个数，不接收输出形状；
- `create_constant()` 不读取 `data_ptr`，不复制权重；
- 激活 tensor 没有 storage 元信息，shape 由后续 Finalizer 推导；
- `dump_ir()` 是只读文本，不是序列化格式；
- `sort_op()` 从输出反向 DFS，未连接到输出的 op 不会进入执行序列；
- 图构建和排序不保证线程安全，应在单线程完成。

## 4. 详细设计

### 4.1 配置模型

`Qwen3Config` 字段如下。默认值即 Qwen3-0.6B 配置；`from_json()` 支持
Transformers 5.9 的 `rope_parameters` 和旧版 `rope_theta` 两种写法。

| 字段 | 默认值 | 用途 |
|------|--------|------|
| `model_type` | `qwen3` | 只接受 qwen3。 |
| `vocab_size` | 151936 | embedding 和 lm_head 输出宽度。 |
| `hidden_size` | 1024 | residual stream 宽度。 |
| `intermediate_size` | 3072 | MLP 中间宽度。 |
| `num_hidden_layers` | 28 | Decoder Layer 数量。 |
| `num_attention_heads` | 16 | Q head 数。 |
| `num_key_value_heads` | 8 | K/V head 数，GQA 比例 2。 |
| `head_dim` | 128 | 每个 head 的宽度。 |
| `hidden_act` | `silu` | 只支持 Qwen3 的 SwiGLU。 |
| `max_position_embeddings` | 40960 | RoPE 和 attention 上界。 |
| `rms_norm_eps` | `1e-6` | 所有 RMSNorm 的 eps。 |
| `rope_theta` | `1000000.0` | RoPE 基频。 |
| `rope_type` | `default` | 只支持默认 RoPE。 |
| `tie_word_embeddings` | `true` | LM Head 是否复用 embedding。 |
| `attention_bias` | `false` | Qwen3-0.6B 无 q/k/v/o bias。 |
| `use_sliding_window` | `false` | 本版本不支持 sliding attention。 |
| `sliding_window` | `null` | 保留字段；关闭时为 0。 |
| `dtype` | `bfloat16` | 权重和激活声明精度。 |

派生值：

```text
q_width  = num_attention_heads * head_dim   = 16 * 128 = 2048
kv_width = num_key_value_heads * head_dim   = 8  * 128 = 1024
gqa_ratio = num_attention_heads / num_key_value_heads = 2
```

注意：Qwen3 的 `hidden_size=1024` 不等于 `q_width=2048`。q_proj 输出
2048 维，o_proj 再投影回 1024 维；不能假设 `hidden_size == heads * head_dim`。

### 4.2 命名规则

| 类别 | 规则 | 示例 |
|------|------|------|
| 图名 | `<model>_<size>` | `qwen3_0_6b` |
| 输入 op | `input.<name>` | `input.input_ids` |
| 输出 op | `output.<name>` | `output.logits` |
| 层内 op | `layer.<i>.<suffix>` | `layer.0.attn_norm` |
| 层内权重 | `layer.<i>.<param>.weight` | `layer.0.q_proj.weight` |
| 全局权重 | `<name>.weight` | `embedding.weight`、`final_norm.weight` |
| 激活 tensor | 由 Graph 自动生成 `<op>.out` | `layer.0.attn_norm.out` |

`Graph_Fixed` 会自动校验 op 名称唯一、tensor 名称唯一。组图层必须保证
constant 名称与 op 名称、自动生成的 `<op>.out` 名称不冲突。

### 4.3 权重/常量登记

每个权重只登记元信息：

```python
graph.create_constant(
    name=weight_name,
    dims=list(shape),
    pitch=list(shape),
    precision=precision,
    layout=Layout.kRowMajor,
    byte_size=element_count * element_bytes,
    data_ptr=0,
)
```

规则：

1. 权重形状采用 Transformers `nn.Linear.weight` 的 `[out_features,
   in_features]` 布局，后续 `kLinear` 的 `transpose_weight=true` 表示
   计算 `x @ W^T`。
2. RMSNorm 权重形状为 `[normalized_shape]`。
3. embedding 形状为 `[vocab_size, hidden_size]`。
4. `tie_word_embeddings=true` 时只创建一个 `embedding.weight` constant，
   `lm_head.weight` 作为逻辑别名复用同一个 `Tensor`，不重复登记 constant。
5. `tie_word_embeddings=false` 时额外登记 `lm_head.weight` constant。
6. `data_ptr=0` 表示权重内容未加载；后续权重加载阶段再回填地址。
7. `byte_size` 只做元信息校验，不分配内存。

### 4.4 通用 op 映射

| 模型语义 | Graph_Fixed OpType | 输入 | 输出 | 关键属性 |
|----------|--------------------|------|------|----------|
| token embedding | `kGather` | input_ids、embedding.weight | hidden | `axis=0`、`vocab_size`、`hidden_size` |
| RMSNorm | `kRmsNorm` | x、weight | normalized | `eps`、`normalized_shape`、`axis=-1` |
| Linear | `kLinear` | x、weight | y | `in_features`、`out_features`、`transpose_weight=true` |
| RoPE | `kRope` | q/k、position_ids | rotated | `head_dim`、`num_heads`、`rope_theta`、`rope_layout=neox` |
| causal GQA | `kMegaAttention` | q、k、v | context | `num_heads`、`num_kv_heads`、`head_dim`、`causal=true`、`softmax_scale`、`merge_heads=true`、`has_output_projection=false` |
| residual add | `kAdd` | x、residual | y | `precision` |
| SwiGLU 前段 | `kLinearSwiGlu` | x、gate.weight、up.weight | act | `activation=silu`、`intermediate_size`、`transpose_weight=true` |
| LM Head | `kLinear` | hidden、lm_head.weight | logits | `in_features`、`out_features`、`transpose_weight=true` |

### 4.5 Qwen3-0.6B 源码映射

参考源码：Transformers 5.9.0
`transformers/models/qwen3/modeling_qwen3.py`。对应关系如下：

| Transformers 源码 | Graph_Fixed 节点 |
|-------------------|------------------|
| `Qwen3Model.embed_tokens` | `embedding`（`kGather`） |
| `Qwen3DecoderLayer.input_layernorm` | `layer.i.attn_norm`（`kRmsNorm`） |
| `Qwen3Attention.q_proj` | `layer.i.q_proj`（`kLinear`） |
| `Qwen3Attention.k_proj` | `layer.i.k_proj`（`kLinear`） |
| `Qwen3Attention.v_proj` | `layer.i.v_proj`（`kLinear`） |
| `Qwen3Attention.q_norm` | `layer.i.q_norm`（`kRmsNorm`，head_dim） |
| `Qwen3Attention.k_norm` | `layer.i.k_norm`（`kRmsNorm`，head_dim） |
| `Qwen3RotaryEmbedding` + `apply_rotary_pos_emb` | `layer.i.q_rope`、`layer.i.k_rope`（`kRope`） |
| `eager_attention_forward`（repeat_kv、QK^T、scale、causal mask、softmax、PV） | `layer.i.attn`（`kMegaAttention`） |
| `Qwen3Attention.o_proj` | `layer.i.o_proj`（`kLinear`） |
| 第一个 `residual + hidden_states` | `layer.i.attn_residual`（`kAdd`） |
| `Qwen3DecoderLayer.post_attention_layernorm` | `layer.i.mlp_norm`（`kRmsNorm`） |
| `gate_proj + up_proj + silu + mul` | `layer.i.mlp_gate_up`（`kLinearSwiGlu`） |
| `down_proj` | `layer.i.mlp_down`（`kLinear`） |
| 第二个 `residual + hidden_states` | `layer.i.mlp_residual`（`kAdd`） |
| `Qwen3Model.norm` | `final_norm`（`kRmsNorm`） |
| `Qwen3ForCausalLM.lm_head` | `lm_head`（`kLinear`） |
| `logits` 返回 | `output.logits`（`kOutput`） |

源码与图的差异：

1. 源码的 `repeat_kv` 由 `kMegaAttention` 的 GQA 属性表达；
2. 源码的 `transpose(1,2)` / `reshape` 由 `kMegaAttention` 的
   `merge_heads=true` 和 `kRmsNorm`/`kRope` 的 head 属性表达；
3. 源码的 causal mask 由 `kMegaAttention.causal=true` 表达；
4. 源码的 `logits_to_keep` 默认 0，本图输出全序列 logits；
5. 源码的 `past_key_values` 不在本图范围，本图是 prefill 图。

### 4.6 Qwen3-0.6B 图结构

```text
input.input_ids ─┐
                 ├─> embedding (Gather) ─> hidden
input.position_ids ────────────────────────┐
                                           │
for i in 0..27:                            │
  attn_norm = RMSNorm(hidden)               │
  q = Linear(attn_norm, q_proj.weight)      │
  k = Linear(attn_norm, k_proj.weight)      │
  v = Linear(attn_norm, v_proj.weight)      │
  q = RMSNorm(q, q_norm.weight, head_dim)   │
  k = RMSNorm(k, k_norm.weight, head_dim)   │
  q = RoPE(q, position_ids) <───────────────┘
  k = RoPE(k, position_ids)
  ctx = MegaAttention(q, k, v)
  attn = Linear(ctx, o_proj.weight)
  hidden_mid = Add(hidden, attn)
  mlp = RMSNorm(hidden_mid, mlp_norm.weight)
  mlp = LinearSwiGlu(mlp, gate_proj.weight, up_proj.weight)
  mlp = Linear(mlp, down_proj.weight)
  hidden = Add(hidden_mid, mlp)

final = RMSNorm(hidden, final_norm.weight)
logits = Linear(final, embedding.weight)   # tie_word_embeddings=true
output.logits = logits
```

每层恰好 15 个 op，顺序固定：

```text
attn_norm -> q_proj -> k_proj -> v_proj -> q_norm -> k_norm
-> q_rope -> k_rope -> attn -> o_proj -> attn_residual
-> mlp_norm -> mlp_gate_up -> mlp_down -> mlp_residual
```

### 4.7 图规模与权重统计

Qwen3-0.6B 默认配置（28 层、tie=true）：

| 项目 | 数量/大小 | 计算方式 |
|------|-----------|----------|
| 图输入 | 2 | input_ids、position_ids |
| 图输出 | 1 | logits |
| 每层 op | 15 | 见 4.6 |
| 计算 op 总数 | 426 | 2 input + 1 embedding + 28*15 + final_norm + lm_head + output |
| constant 总数 | 310 | 1 embedding + 28*11 + 1 final_norm |
| 逻辑权重参数 | 596,049,920 | 与 Transformers meta 模型一致 |
| bfloat16 字节数 | 1,192,099,840 | 596,049,920 * 2 |
| 每层权重参数 | 15,730,944 | q/k/v/o + q_norm/k_norm + mlp + norms |
| 每层 constant | 11 | attn_norm、q、k、v、o、q_norm、k_norm、mlp_norm、gate、up、down |

`tie_word_embeddings=false` 时，constant 总数变为 311，逻辑权重参数增加
`vocab_size * hidden_size = 155,582,464`。

### 4.8 异常与错误处理

| 场景 | 行为 |
|------|------|
| 配置字段非正数 | `ValueError`，消息包含字段名 |
| `hidden_act != silu` | `ValueError`，当前只支持 Qwen3 SwiGLU |
| `attention_bias=true` | `ValueError`，当前未实现 bias 常量 |
| `dtype` 不在 bfloat16/float16/float32 | `ValueError` |
| `rope_type != default` | `ValueError`，未实现 scaling |
| `use_sliding_window=true` | `ValueError`，当前只画 full attention |
| `num_attention_heads % num_key_value_heads != 0` | `ValueError`，GQA 比例必须整除 |
| 图名/权重名重复 | `Graph_Fixed` 抛 `RuntimeError` |
| 输入/输出 tensor 不属于当前图 | `Graph_Fixed` 抛 `RuntimeError` |
| `_graph_fixed` 扩展缺失 | `ModuleNotFoundError`，提示设置 `GRAPH_FIXED_PYTHON_DIR` |

### 4.9 关键实现细节

1. **构建一次性**：`Qwen3GraphBuilder.build()` 每次创建新的 `Graph`，
   避免重复调用时名称冲突。
2. **常量映射**：builder 内部维护 `weight_shapes` 和
   `graph_constant_shapes`；前者包含 tied `lm_head.weight` 别名，后者只含
   实际登记的 constant。
3. **输入精度**：`input_ids` 和 `position_ids` 使用 `Precision.kInt64`，
   layout 为 `kRowMajor`。
4. **激活精度**：所有计算 op 的 `precision` 属性写 `bfloat16`，但激活
   tensor 本身没有 storage；精度由后续推导阶段处理。
5. **RoPE**：`kRope` 融合 `Qwen3RotaryEmbedding.forward` 和
   `apply_rotary_pos_emb`；`rope_layout=neox` 对应源码的 `rotate_half`。
6. **Attention**：`kMegaAttention` 的 `has_output_projection=false`，o_proj
   单独成节点，保持与源码一致；`merge_heads=true` 表示输出
   `[batch, seq, q_width]`。
7. **残差**：第一个 Add 的第二个输入是层输入 `hidden`；第二个 Add 的第二
   个输入是 `hidden_mid`，不能误用 `hidden`。
8. **输出**：`create_output("output.logits", logits)` 不创建新 tensor，只
   建立图输出边界。
